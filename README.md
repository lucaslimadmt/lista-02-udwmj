# Exercícios Práticos de HTML e CSS

Repositório contendo a resolução de exercícios práticos para fixação dos conceitos fundamentais de HTML5 e CSS3.

---

## 📋 Conteúdo dos Exercícios

1. **Cartão de Apresentação**: Estruturação de perfil com centralização em Flexbox.
2. **Perfil de Personagem**: Aplicação de imagens com borda arredondada e estilos específicos.
3. **Receita Simples**: Utilização de listas ordenadas (`<ol>`) e não ordenadas (`<ul>`) com diferenciação de estilos.
4. **Botão Estilizado**: Criação de link interativo com efeito pseudo-classe `:hover`.
5. **Card de Notícia**: Agrupamento em container (`<div>`) com cantos arredondados e largura máxima.
6. **Tabela de Preços**: Construção de tabela (`<table>`) estilizada com alinhamentos e cores de cabeçalho.
7. **Rodapé de Site**: Implementação da tag semântica `<footer>` com links de contato.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5**
* **CSS3**
